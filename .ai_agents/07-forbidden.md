# 07-forbidden.md

## 明确禁止事项
- 禁止脱离当前工程风格随意改写代码
- 禁止过度设计、过度抽象、过度封装
- 禁止无明确要求的大规模重构
- 禁止顺手修改无关代码
- 禁止擅自新增第三方依赖
- 禁止擅自修改公共接口
- 禁止擅自修改对外字段名
- 禁止擅自修改 tag
- 禁止擅自修改错误语义和响应结构
- 禁止修改后不做格式化
- 禁止未检查就宣称可编译
- 禁止未测试就宣称测试通过

## 高风险操作默认不执行
以下行为默认不执行，除非任务明确要求：
- 调整目录结构
- 调整模块边界
- 改写并发模型
- 修改事务逻辑
- 修改幂等、重试、回滚逻辑
- 修改数据库字段语义
- 修改 API 返回结构
