# 07-forbidden.md

## 禁止
- 脱离现有工程风格随意改写
- 过度设计、过度抽象、过度封装
- 无明确要求的大规模重构
- 顺手改无关代码
- 擅自新增第三方依赖
- 擅自修改公共接口、对外字段名、tag、错误语义、响应结构
- 修改后不格式化，未检查/测试却宣称通过
- 将编译产物、中间文件放到工程目录中，如 `mlc_server`、`*.exe`、`*.o`、`*.a` 等二进制文件
- 在日志、错误、调试输出中打印密码、Token、密钥、身份证号、手机号等敏感信息或 PII
- 使用破坏性命令或不可逆操作处理代码、数据、迁移和 Git 历史

## 高风险默认不执行
- 调整目录结构
- 调整模块边界
- 改写并发模型
- 修改事务、幂等、重试、回滚逻辑
- 修改数据库字段语义
- 修改 API 返回结构
- 引入新的日志采集、脱敏或安全组件
- 大范围替换 SQL、缓存 key、错误码、权限判断或鉴权链路
