# 07-forbidden.md

## 禁止
- 脱离现有工程风格随意改写
- 过度设计、过度抽象、过度封装
- 无明确要求的大规模重构
- 顺手改无关代码
- 擅自新增第三方依赖
- 擅自修改公共接口、对外字段名、tag
- 擅自修改错误语义和响应结构
- 修改后不格式化
- 未检查就宣称可编译
- 未测试就宣称测试通过
- 把缓存、测试产物、调试日志等留在工程目录
- 在日志、错误、调试输出中打印密码、Token、密钥、身份证号、手机号等敏感信息或 PII

## 高风险默认不执行
- 调整目录结构
- 调整模块边界
- 改写并发模型
- 修改事务逻辑
- 修改幂等、重试、回滚逻辑
- 修改数据库字段语义
- 修改 API 返回结构
- 引入新的日志采集、脱敏或安全组件
