## 核心目标
- 按千万级高并发生产级后端工程处理，优先正确、兼容、可编译、可验证
- 数据库增删改查默认面向亿万级别数据表，不按小表、低频后台或单机低压场景假设
- 数据库、缓存、队列、外部 I/O、API 热点路径默认按千万级并发生产约束评估容量、延迟、锁竞争、热点、限流、降级和失败模式
- 接口和功能实现必须先满足业务功能正确可用，再对齐千万级并发、亿万级数据量和生产级稳定性要求做必要优化
- 修改前先理解任务、规则、上下文、调用链、相似实现和影响范围
- 优先复用现有实现和项目风格；不足时只做最小必要扩展
- 涉及 SQL / 数据 / 高并发 / 安全时，叠加对应模块规则执行
