# 00-core.md

## 核心
- 千万级并发后端工程标准
- 优先复用现有实现
- 保持正确、可读、兼容、可编译
- 主流稳定分层架构与设计模式

## 边界
- 不做无关改动
- 调整目录、边界、分层前先确认
- 不擅改公共接口、字段定义、错误语义、执行顺序
- 发现架构不适合千万高并发：先短建议，再等确认

## 方式
- 先看上下文、调用链、影响范围
- 修改前优先使用 `grep` / `glob` 全局搜索相关定义、引用和相似实现
- 先找相似实现
- 优先贴近现有项目习惯
- 确认后落实代码、测试、验证和真实说明
- 连续 3 次编译、测试或修复失败时停止自我循环，说明困境并向用户求助
