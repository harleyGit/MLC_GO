# 01-style.md

## 命名
- 命名延续 Go API 风格
- API 路径、JSON 字段、术语、缩写优先复用现有命名

## 风格
- 保持现有代码组织、函数拆分、错误处理、返回值风格一致
- 保持注释、日志、字段顺序风格一致

## 注释
- 只写有信息量的注释
- 复用或修改既有代码时，默认保留原有注释；若注释已失真、误导或不合理，先删除或改写，再补充准确注释
- 新增或修改方法、函数：补 1~2 行职责注释
- 关键逻辑写清约束：鉴权、签名、防篡改、事务、重试、缓存
- 入口分发函数写清职责与设计目的
- Shell / Bash / 运维脚本注释更详细

## 日志
- 不加无价值日志
- 不输出敏感信息
