# 01-style.md

## 命名
- 命名延续 Go API 风格
- API 路径、JSON 字段、业务术语、缩写优先复用现有命名
- 新增文件、类型、函数、变量、常量等命名必须以 `HG` 或 `hg` 开头；包名仍遵循 Go 小写短名规则

## 风格
- 保持现有代码组织、函数拆分、错误处理、返回值风格一致
- 保持注释、日志、字段顺序风格一致

## 注释
- 只写有信息量的注释
- 保留准确旧注释；失真注释先删改，再补准确信息
- 导出类型/方法、入口分发、关键逻辑写清职责和约束
- 结构体用到接口或协议时，注释需写明接口/协议名称、用途和约束
- 关键约束包括鉴权、签名、防篡改、事务、重试、缓存、单位、枚举、默认值
- Shell / Bash / 运维脚本注释更详细

## 日志
- 不加无价值日志
- 不输出敏感信息
