# 04-data-rules.md

## Repository / DAO
- 数据访问层写法与当前工程保持一致。
- 不擅自切换 SQL 写法、ORM 用法、查询封装方式。
- 不擅自改变 repository / dao 的职责边界。

## SQL / ORM
- 保持现有查询风格一致。
- 不擅自改动字段映射、筛选条件、排序逻辑、分页逻辑。
- 不因局部优化改变已有查询语义。
- 涉及事务逻辑时必须谨慎，优先延续现有实现模式。

## 数据兼容性
- 不擅自修改数据库字段含义。
- 不擅自修改 model 与数据库字段的映射关系。
- 不擅自修改序列化字段和 tag。
- 优先保证兼容性和正确性。

## Model / Entity / DTO
- 不混淆数据库模型、接口模型、业务模型。
- 不因临时方便而随意合并或拆分模型。
